## 变更

- 自 KCoder 内置包 dsh-git-panel 独立发布：npm 首发版本 1.0.0，与内部版本号历史切割。
- npm 无 scope 名 dsh-git-panel 已被社区第三方插件占用（E403）；先取 @dsh-external scope，该 org 名被 npm 注册政策拦截（「名字无效」），定稿用户名 scope @kkutysllb（零前置天然可用）；dsh-plugins 镜像目录名与内部 RPC 前缀 /dsh-git-panel/api 保持不变。
- 功能与 dsh-git-panel 终版一致；内部路由/锚点前缀由 kc- 统一为 dsh-（除本插件外无外部消费者）。

## 安装

```bash
dsh plugin --profile web add @kkutysllb/dsh-git-panel
```
