# @kkutysllb/dsh-git-panel 1.1.1

## 变更

### 任务计划点击 → 原生右栏文档预览（本次主题）

- **旧行为**：面板里点计划文档，先试 KCoder better-sidebar 的 editor tab（该产品已
  退役这块面板），否则走 server `open-plan` → **本机默认应用**（Finder 预览 /
  编辑器 / IDE），把用户踢出 dsh 界面。
- **新行为**：三级链，**首选原生右栏文档预览**——
  1. `ctx.sidebarRight.openResource(address)`（`ui-sidebar-right` 对外 client 服务，
     `ui-sidebar-documentpreview` 收 `dsh-resource://file/**`）：
     - 路径在会话工作区内 → `dsh-resource://file/session/<sessionId>/<相对路径>`
       （与 shell 里点文件引用同一形态，Host 按会话根解析）；
     - 路径在区外（如 worktree 覆盖）或取不到会话 → `dsh-resource://file/absolute/…`；
     地址按 `encodeURIComponent` 分段编码、`:` 保持字面（与
     `@deepseek-ai/dsh-util-workspace-path` 的 `fileAddressFor`/`absoluteFileAddress` 同款）。
  2. 原生服务缺席时回落 KCoder better-sidebar editor tab（保留兼容）；
  3. 两者都不可用才走 server `open-plan`（系统默认应用）兜底。
- `openResource` 同一步展开原生右栏；本面板按既有的**互斥让位**自动收起，
  预览关掉后履约回开——不再弹本机应用，也不再与右栏叠着。
- smoke 增补该链路的形态断言。
