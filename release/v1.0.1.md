# @kkutysllb/dsh-git-panel 1.0.1

## 变更

- 新增 GitHub 管理（gh CLI 软依赖）：面板新增 GitHub 区块，标题展示 owner/repo——
  - 开放 PR / Issue 清单：数量徽标；行点击系统浏览器打开；当前分支命中的 PR 打「当前」标，草稿 PR 打「草稿」标；
  - 一键创建 PR：flyout 填标题/描述；当前分支未推送或落后上游时自动 `push -u`；
  - PR Squash 合并：行内二次确认（merge|squash|rebase 可经 RPC 指定，缺省 squash；草稿不出合并动作）；
  - 新建 Issue：flyout 填标题/描述。
- 新增 RPC：`gh-list` / `gh-create-pr` / `gh-merge-pr` / `gh-create-issue` / `open-url`（http/https 白名单外链浏览器打开）。gh 全部 execFile 直调，无 shell 拼接；标题 ≤500 字、描述 ≤4000 字在触 gh 前拒绝。
- gh 数据懒加载（展开/开板/动作后拉取），不进 15s 轮询；worktree/会话切换自动失效重拉。
- gh CLI 未安装或未登录时区块降级为安装/登录提示（含重试入口），git 面板本体不受影响。
- 修复：flyout 内按钮复用 `.gt-abtn` 样式时作用域未覆盖弹层，创建分支按钮裸奔的视觉问题。

## 安装

```bash
# npm registry（推荐：版本可被插件管理检测，用户手动更新）
dsh plugin --profile web add @kkutysllb/dsh-git-panel

# 或 GitHub 直装 / dsh-plugins 真源仓
dsh plugin --profile web add github:kkutysllb/dsh-git-panel
dsh plugin --profile web add github:kkutysllb/dsh-plugins#dsh-git-panel
```

gh 管理能力需本机装有 [gh CLI](https://cli.github.com) 并 `gh auth login`；
缺席仅降级 GitHub 区块，其余功能不受影响。
