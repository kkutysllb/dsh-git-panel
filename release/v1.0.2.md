# @kkutysllb/dsh-git-panel 1.0.2

## 变更

- QiLin（麒麟）双通道适配：manifest 同时声明 `qilin` 与 `dsh` 两个通道的
  `bundle.patch` / `client`，指向同一份 `cordis.patch.yml` 与 client 交付物，
  行为完全一致——QiLin（dsh 0.1.6-alpha.2 合并后）的插件管理器只认原生键
  `qilin.bundle.patch`（缺失会报「没有声明组合包」），DSH 宿主仍读 `dsh.*`。
- 新增麒麟（QiLin）引擎安装途径：README 增补 `qilin plugin --profile qilin add`
  安装章节与注意事项——包必须经 `qilin plugin add` 落到 profile 私有的
  `~/.qilin/profiles/<name>/node_modules`（共享 node_modules 是安装保留区，
  手放会 `failed to import`）；运行需带 dsh 兼容层的 QiLin 3.0.0+，插件管理
  （设置页展示/启停）要求 3.0.2+；dsh alpha.2 起运行时解析模式下本包
  host 侧零 npm 运行时依赖，天然兼容。
- client 卸载收口（运行时停用/HMR）：保活轮询、body MutationObserver、
  文档级 mousedown/keydown 监听全部具名化，新增 `teardown` 经
  `ctx.effect` 注册 disposer——停用/热替换时清定时器与监听、还原布局
  inset、移除注入 DOM 与 `window.__dshGitPanel*` 全局钩子并复位 Wired
  守卫，插件启停循环与热更新不再残留。

## 安装

dsh（DSH 宿主）：

```bash
# npm registry（推荐：版本可被插件管理检测，用户手动更新）
dsh plugin --profile web add @kkutysllb/dsh-git-panel

# GitHub 直装 / dsh-plugins 真源仓
dsh plugin --profile web add github:kkutysllb/dsh-git-panel
dsh plugin --profile web add github:kkutysllb/dsh-plugins#dsh-git-panel
```

QiLin（麒麟引擎）：

```bash
# npm registry（推荐：版本可被插件管理检测，用户手动更新）
qilin plugin --profile qilin add @kkutysllb/dsh-git-panel

# GitHub 直装
qilin plugin --profile qilin add github:kkutysllb/dsh-git-panel
```

Git 面板需要系统 git（gh 可选）；QiLin 侧装完在 设置 → 插件
可见、可启停（引擎 3.0.2+）。
