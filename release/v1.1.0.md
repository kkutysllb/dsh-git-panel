# @kkutysllb/dsh-git-panel 1.1.0

## 变更

### 1. 开关按钮锚点链（原生壳可用性 + 桌面壳让位原生按钮，本次主题）

- **症状 A（原生壳无入口）**：dsh 0.2.x 原生壳（`dsh web` / 原生桌面）下
  **右上角没有 git 按钮**，面板无任何入口——v1.0.x 只认 KCoder 桌面壳主进程
  注入的 `#__dsh_desktop_titlebar`（theme-watcher / QiLin titlebar.mjs），原生壳
  没有该元素，`injectBtn()` 恒为假。
- **症状 B（桌面壳压住原生按钮，2026-10-10 实机反馈）**：KCoder 桌面壳把会话
  页头**覆盖进**自绘标题栏同一条 48px 带（页头 z 2147483647 > 条 z 2147483646），
  带内右侧已由原生按钮占位（本地编辑器选择 / 远程 SSH）。v1.0.x 的标题栏位形是
  固定 `absolute; right:108px`——正好压在原生编辑器选择按钮上。
- **改法**：锚点链（纯 DOM，不引入上游 slot 依赖），**会话头 corner 优先**：
  1. `[data-slot="conversation.session.header.corner"]`（slot 工具化 DOM，
     `display:contents` 包装；兜底选择器 `data-conversation-header-corner`）：
     行内 28px、与邻居 icon 按钮齐平、`-webkit-app-region:no-drag`、色随
     `currentColor`。它是会话头自己的行内末席，页头排布已为右侧原生按钮带留出
     空间 ⇒ 既不重叠、也不吃别家按钮。
  2. 兜底 `#__dsh_desktop_titlebar`：仅当**没有会话头**时（hero/设置页）按钮回落到
     桌面壳标题栏带，沿用 `absolute; right:108px` 旧位形，v1.0.x 观感不变。
- **位形随锚点**：corner 位形走 `.gt-corner`（行内 28px），标题栏位形走绝对定位；
  会话页 ↔ hero/设置页之间迁移由 500ms 巡逻完成，SPA 重挂/整表重写永续自愈。
  巡逻只在按钮新建/迁位时重绘徽章，心跳不重建 DOM。

### 2. 当前会话三级来源（面板数据链修复，本次第二主题）

- **症状**：面板恒显「等待工作区…」，计数全 0，从不调用自己的
  `/dsh-git-panel/api/snapshot`。
- **根因**：cwd 唯一来源是 `ctx.get('sessions').list.getSnapshot().current`，而
  `SessionListState` 自 **0.1.6-alpha.2**（提交 `6830e1460d`）起已移除
  `current`——选择归 ui-workspace 的私有 selection store，列表快照只剩
  `ids/byId/phase/projectionsBySession`。
- **改法**：三级来源，任一级命中即用 `byId` 读 cwd：
  1. 列表快照 `current`（≤0.1.5 老宿主遗留，保持兼容）；
  2. 侧栏当前会话行 `[data-row-key^="session:"][aria-selected="true"]`
     （ui-workspace `Rows.tsx` 的稳定 DOM 事实，切会话即时跟随）；
  3. 选择持久值 `localStorage['dsh.sessions.current']`（selection store 的
     persist 名，形如 `{sessionId}`）——分组收起/行未渲染时兜底。
- 会话切换跟随：body observer 把 `aria-selected` 翻转当信号立即重拉（不等
  15s/60s 轮询）；`class` 抖动（流式渲染高频）不进跟随判定。
- 刷新加在途序号：并发切换时旧响应不再覆盖新响应；瞬时取不到沿用上次成功
  解析的 cwd，不闪空态。

### 3. 与原生右侧栏互斥让位（2026-10-10 实机反馈）

- **症状**：原生右栏（`ui-sidebar-right`，第三列轨道 `[data-rightbar-col]`）展开后，
  git 浮层整个压住它（原 `detailsCol` 内缩写法在 0.2.x 改名 `rightbarCol` 后失效，
  而且内缩会切掉右栏自身内容）。
- **改法（双向互斥，带履约义务）**——
  - 反向：任一右栏展开（原生 `ctx.sidebarRight.isExpanded()`，或 KCoder
    better-sidebar）→ git 面板自动收起；该右栏收起 → 履约恢复（仅「因让位而
    收起」才恢复，用户手动开关不参与义务）；
  - 正向：git 面板开启 → 开着的右栏收起避让（原生走
    `ctx.sidebarRight.toggleExpanded()`）；手动关 git → 履约开回；
  - 服务缺席的老宿主：正向不动它，退化为**几何互避**——按轨道
    `getBoundingClientRect().width` 把浮层左移到 `右栏宽 + 12px`，收起回右缘，
    拖拽调宽与全屏态都有兜底（全屏时右栏铺满帧，维持右缘浮层不越界）。
- 让位只缩中心列（`centerCol`），不再内缩右栏。沿判定翻转才动作，
  observer 监听 `data-rightbar-collapsed` / `data-rightbar-fullscreen`，
  500ms 心跳兜住服务侧翻转。

### 4. 任务计划文档递归扫描（2026-10-10 反馈）

- **旧行为**：只扫工作区根下的 `plans/`、`docs/plans/`、`.plans/` **一层** + 根
  `plan.md` 等三个约定文件。
- **新行为**：递归，次级目录一样收——
  - **约定目录**：任意层级的 `plans/` 与 `.plans/` 子树，其下 `.md` 全收
    （如 `packages/foo/plans/x.md`、`plans/2026-10/sub/deep.md`）；
  - **约定文件**：根 `plan.md` / `PLAN.md` / `docs/plan.md`，外加任意层级的同名
    `plan.md`。
- **有界**：深度 6 / 目录 600 / 文件 80（防巨型仓拖慢每次快照轮询）；跳过
  `node_modules`、`.git`、`dist/build/out/coverage`、`vendor/target`、各类缓存与链接
  worktree；模板/夹具目录（`templates`/`fixtures`/`__snapshots__`）里的样板
  `plan.md` 不算计划。每层先下钻「本身就是约定目录」的分支，预算被吃光时先保住
  计划目录的召回。
- 面板空态提示同步为「约定位置（递归任意层级）」。
- 实测：`deepseek-harness` 32ms 命中 `docs/subsystems/plan.md`（旧版扫不到）；
  `KCoder` 13ms，6 条全是真计划——此前被技能模板 `templates/plan.md` 占掉的那格
  换成了真计划。

### 5. manifest 新代兼容声明

- `dsh.manifestVersion: 1`；
- `engines.dsh` 与两条 `peerDependencies`（`@deepseek-ai/dsh`、
  `@deepseek-ai/dsh-host-webserver`）同为 `>=0.1.6-alpha.2 <1.0.0`——供
  plugin-manager 安装前检查与 app-boot 启动准入评估（两处共用
  `plugin-compatibility.ts` 检查器，`includePrerelease: true`）。
- **上界必须 <1.0.0 而不是 <0.2.0**：窄上界会让整个 bundle 在 0.2.x 被静默跳过
  （同门 dsh-terminal 1.2.2 的现场）。本版声明覆盖 0.1.6-alpha.2 ~ 0.2.x 全系。

## 升级

```bash
dsh plugin --profile <name> add @kkutysllb/dsh-git-panel@latest
```

官方桌面端 UI 无原地更新时：插件详情页「卸载」→ 安装框重装
`@kkutysllb/dsh-git-panel`。纯 client 面 + manifest 改动，刷新页面即生效
（manifest 变更需重启引擎生效）。
